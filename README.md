# Landing Page — Óptica Prado

Landing page comercial para a Óptica Prado (Teresina-PI), com apresentação de produtos, atendimento via WhatsApp e informações de contato.

🔗 **Demo ao vivo:** https://opticasprado-the.vercel.app

## ✨ Funcionalidades

- Vitrine de produtos e serviços da ótica
- Botão de contato direto via WhatsApp
- Perfil do responsável técnico e endereço da loja
- Design responsivo e deploy contínuo via Vercel

## 🚀 Como rodar localmente

```bash
git clone https://github.com/watsonndantas/opticasprado-the.git
cd opticasprado-the
npm install
npm run dev
```
